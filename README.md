شفاء الباحة الذكي (Shifa Al-Baha Smart Heal)
خدمة ذكية مقترحة لأتمتة رحلة طلب العلاج والإخلاء الطبي، مصممة لتكون مدمجة داخل بوابة إمارة الباحة الإلكترونية.
نبذة
تحوّل الخدمة رحلة طلب العلاج أو الإخلاء الطبي من إجراءات متفرقة إلى مسار رقمي واحد، من تقديم الطلب حتى إغلاق الحالة. تعتمد على مساعد ذكي لفهم الحالة، استخراج بيانات التقارير الطبية آلياً، تصنيف الأولوية، مطابقة المستشفى المناسب، وتنسيق النقل، مع لوحة عمليات مركزية للجهات المعنية.
هذا نموذج أولي قدم ضمن هاكاثون الخدمات الإلكترونية الحكومية، ويستخدم بيانات تجريبية بالكامل لمحاكاة التشغيل. النظام لا يتخذ أي قرار طبي مستقل، ويبقى الاعتماد النهائي دائماً للطبيب المختص.
المشكلة والحل
رحلة العلاج والإخلاء الحالية متفرقة، تكرار إدخال البيانات، تعدد قنوات التقديم، تنسيق يدوي بين الجهات، وغياب مسار موحد للمتابعة.
الحل يقوم على طبقتين، معالجة ذكية للفرز والتحقق من اكتمال البيانات وتحديد الأولوية، ومزامنة بيانات لتحديث تلقائي من المصدر الرسمي. النتيجة طلب واحد، بيانات متسقة، ومتابعة موحدة حتى الإغلاق.
رحلة المستفيد
الدخول عبر نفاذ، ثم المساعد الذكي يحدد نوع الحالة، ثم تحديد الموقع، ثم رفع التقرير الطبي واستخراج بياناته، ثم تحديد الأولوية، ثم مطابقة المستشفى، ثم تأكيد القبول، ثم تحديد وسيلة النقل، ثم التتبع المباشر، ثم الاستلام وإغلاق الطلب وتقييم الخدمة.
المميزات الرئيسية
واجهة ثنائية اللغة عربي وإنجليزي. مساعد ذكي للفرز مع إسعافات أولية عامة عند الحاجة وتنبيه دائم بعدم بديليتها عن الاتصال بالرقم 997. استخراج آلي لبيانات التقارير الطبية. محرك مطابقة بين احتياج المريض وإمكانات المستشفيات. لوحات منفصلة للطبيب، والمستشفى، وغرفة العمليات المركزية.
إخلاء مسؤولية
جميع البيانات بيانات تجريبية لأغراض العرض فقط. الذكاء الاصطناعي يقدم توصيات مساندة فقط، ولا يصدر تشخيصاً أو قراراً مستقلاً، ويبقى الاعتماد النهائي دائماً للطبيب والجهة المختصة.
التقنيات
React، TypeScript، Tailwind CSS، shadcn ui، Vite، Supabase عند التفعيل.
